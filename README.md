## ✨ Fitur Utama

- ✅ **Jurnal dengan Foto** — Tambah catatan harian lengkap dengan foto dari kamera atau galeri
- ✅ **Lokasi Otomatis** — Ambil lokasi GPS + nama tempat lewat reverse geocoding
- ✅ **Cuaca Real-time** — Data cuaca otomatis dari Open-Meteo API saat jurnal dibuat
- ✅ **Mood Tracker** — Catat suasana hati dengan 6 pilihan emoji
- ✅ **Edit & Hapus Entri** — Kelola jurnal kapan saja, lengkap dengan konfirmasi sebelum hapus
- ✅ **Search & Filter** — Cari jurnal lama dengan cepat
- ✅ **Persistensi Data** — Semua data tersimpan otomatis lewat AsyncStorage, tetap ada walau app ditutup

---

## 🔧 Tech Stack

| Teknologi | Kegunaan |
|-----------|----------|
| React Native + Expo | Framework utama pengembangan aplikasi mobile |
| expo-image-picker | Ambil foto dari kamera atau galeri |
| expo-location | Ambil data GPS & reverse geocoding lokasi |
| AsyncStorage | Penyimpanan data lokal offline |
| Open-Meteo API | Data cuaca gratis berdasarkan lokasi |

## 📦 Cara Menjalankan

```bash
git clone https://github.com/Juaan2005/PhotoJurnal.git
cd PhotoJurnal
npm install
npx expo start
```

Scan QR Code menggunakan **Expo Go** di HP Android/iOS.
